# ADR 006: Conditional consideration and move probability are separate

Status: accepted for the local diagnostic profile.

A non-transfer does not reveal a zero fee, and a rumor does not create a transaction label. A player has no exchange-quoted spot price.

Decision: Define next-window permanent-move probability separately from guaranteed consideration conditional on a comparable move. Keep optional payments, loans, salary and actual observations apart.

Consequence: Sold-player selection and disclosure remain major biases. A competing-risk loan/permanent model and a free-transfer atom require additional implementation and lawful data before promotion.
