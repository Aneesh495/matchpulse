# ADR 009: Require source-specific rights before coverage promises

Status: accepted for the local diagnostic profile.

Open access and redistribution permission are different. A public research dataset cannot establish live-feed rights.

Decision: The authored fixture is redistributable. External archives require operator-declared local research authorization. Live envelopes require a registered source, redistribution flag and source freshness SLO.

Consequence: These checks enforce a configuration contract; they cannot adjudicate a legal license. Actual live integration remains blocked, and external raw data never enters public packaging by default.
