# Feed missingness

Event feeds observe selected on-ball actions. Tracking, physical load, intent, coverage and available passing options are absent from the local fixture and archive adapter. A missing pass outcome is distinct from a failed pass. A missing shot-quality model is distinct from zero shot quality. The [contract](../../matchpulse/contracts.py) requires a definition whenever xG appears and rejects malformed Boolean outcomes. The reducer records unsupported event fields rather than silently awarding zero-quality evidence.

Missingness is plausibly not random: league resources, provider scope, camera availability and event salience influence observed fields. A rich competition may supply pressures, body parts and spatial context while a lower division supplies only cards and goals. Comparing ratings across those feeds without support stratification would confound performance with measurement coverage. The UI's coverage page therefore shows unsupported fields, actual acquired fixture count and missing registry denominators.

The archive adapter preserves absent provider publication timestamps and warns that a current file is not a historical live log. Its tests intentionally include a later position record and verify it does not overwrite the initial role. Diagnostic synthetic masks exercise numerical handling but cannot estimate real missingness mechanisms. Full-context versus event-only ablations, field-by-field acquired competition-season matrices, and missingness sensitivity analyses remain incomplete. See [data rights](../DATA_RIGHTS.md) for the current zero actual-event acquisition denominator.
